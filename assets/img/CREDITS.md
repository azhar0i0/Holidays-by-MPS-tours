## Logo

`assets/logo.svg` (and `assets/logo-knockout.svg`, the light version for dark
backgrounds) are vector rebuilds of the Holidays by MPS Tours mark. The wordmark is
set in Plus Jakarta Sans ExtraBold and converted to outlines, so the files carry no
font dependency. The same artwork is inlined in `index.html` as the `#logo-full` and
`#logo-knockout` symbols.
